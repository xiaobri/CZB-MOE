# Window-conditioned temporal weighting control

The paired contrast is **dynamic minus fixed** positive-class window F1. The dynamic arm reruns the published full model. The fixed arm replaces the input to each region's existing temporal scorer with eight distinct, deterministic position vectors, shared by all windows. For segment index j=1 through 8 and feature coordinate k=0 through d−1 the code is √2 cos(π j (k+0.5)/d). Each region can still learn a different eight-position weighting profile. Both arms pool the actual EEG features, retain the peak-shape and global adjustments, train with the original supervision, and use the same within-acquisition pair comparisons and score-refresh rule. Source encoders stay frozen.

Both arms start from scratch for seeds 3 and 42 using the original six-expert protocol, 20 epochs, 20,000 draws per epoch, batch 128, learning rate 0.0005 and 99 Xiehe thresholds. Verify all trainable initial weights, number of trainable parameters and every epoch's sampled indices and batch order across arms. For each trained model select the Xiehe validation checkpoint and threshold with the highest positive-class F1, using the original trainer's tie rule. Lock checkpoint identity and threshold before external inference.

Report F1 for both seeds and the two-seed mean on Xiehe validation and on all windows at Qilu, Tiantan, Chifeng and Xi'an. The external summary weights hospitals equally. Use unrounded values for differences and report both positive and negative results. The historical full-model scores are a reproducibility reference. Use the fresh paired fits for the comparison. These hospitals were previously evaluated in the project. This contrast tests dependence of the temporal scorer on window content within this model. Two seeds and the choice of a specific fixed-position encoding limit generalization.
