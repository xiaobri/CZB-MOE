# Component attribution on Xiehe

The target is the positive-class validation F1 change from the published strict six-expert baseline to the published full model. Use seeds 3 and 42, 400,000 draws per fit, the same order of native batches and the same 99 source thresholds. Select each checkpoint by the original 20-epoch best-F1 rule, using the later epoch on an exact tie. Use raw Xiehe EEG at the locked threshold for comparisons of independently trained arms. Report the full effects in each seed, including negative differences. Hospitals and their labels play no role in this source analysis.

1. Reconstruct the ordered sequence of independently fitted models: strict core, first detached regional-statistics correction with acquisition weights and within-batch ranking, peak-shape correction, eight-segment temporal and global adjustments, regional auxiliary supervision, same-acquisition historical pair correction, then refreshing both scores. The last four archived refresh arms and the paired fixed-position control are independent checks of specific mechanisms.
2. In the first correction, run a two-by-two experiment crossing acquisition weighting and hard-negative ranking. Every arm uses the same 1,775,702-parameter first-stage model, focal task, identical initialization within seed, sampling and optimizer. The weighting switch combines class-conditional inverse group frequency (power 1, cap 64) with an exponential moving average of group risk. Rank uses the top 16 negatives per batch and coefficient 0.03. Report four simple effects and their difference of differences.
3. At the weighted + ranked setting compare static weights with adaptive weights. Mask inputs to the same trainable model to compare expert scores alone, scores plus router embeddings, that same context plus per-region activation means, and full activation mean, maximum and standard deviation. Masked coordinates are zero. These controls match nominal parameter count; masking changes the information available to those parameters.
4. Read intermediate heads from the original final fits to check the separately trained sequence. Report comparisons with each head's own source-selected epoch and with the epoch fixed by the final head. These are paired readouts from a single fit and exclude retraining variation.

All module increments depend on the order and on the active companion components. Classify references by implementation, methodological antecedent or exploratory alternative. Standard supervision or backbone choices shared with the baseline receive no incremental F1 credit.
